# 햇빛을 피해라! 선글라스 챌린지

스포츠 선글라스의 필요성을 짧은 회피 게임으로 체험하는 웹 기반 프로모션 미니게임입니다.

## 실행 방법

별도 설치 없이 프로젝트 폴더에서 로컬 서버만 실행하면 됩니다.

```powershell
npm start
```

브라우저에서 `http://localhost:4173`으로 접속합니다.

## 조작 방법

- PC: 방향키 또는 게임 영역에서 마우스 이동
- 모바일: 게임 영역을 터치하거나 좌우로 드래그
- 20초 동안 햇빛 장애물을 피하면 성공합니다.
- 3회 충돌하면 실패합니다.

## 상품 URL 교체

`game.js` 상단의 `PRODUCT_URL` 값을 실제 상품 URL로 변경하면 됩니다.

```js
const PRODUCT_URL = "https://example.com/product";
```

현재 버튼은 과제용 안내 메시지만 표시하며 실제 쿠폰을 발급하지 않습니다.
