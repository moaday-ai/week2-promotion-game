# 선글라스 가격 맞히기

선글라스 이미지를 보고 퀴즈용 예시 가격을 고르는 모바일 우선 프로모션 게임입니다.

## 실행

프로젝트 루트에서 다음 명령을 실행합니다.

```powershell
npm start
```

브라우저에서 아래 주소로 접속합니다.

`http://localhost:4173/game-4-price/index.html`

## 문제 데이터 교체

문제, 이미지, 가격 선택지, 정답, 해설은 `questions.js`에 모여 있습니다.

- `image`: `game-4-price/` 기준 이미지 경로
- `alt`: 이미지 대체 설명
- `options`: 숫자로 저장하는 가격 선택지 4개
- `answerIndex`: 정답의 배열 위치(0부터 시작)
- `explanation`: 답을 공개한 뒤 표시할 짧은 해설
- `priceType`: 가격 성격. 현재는 `quiz-example`

가격은 화면에서 한국 원화 표기로 자동 변환됩니다. 실제 판매가격을 사용하려면 검증된 상품 데이터로 교체하고 안내 문구도 함께 검토해야 합니다.

## CTA 연결

`questions.js`의 `ctaUrl`을 상품 페이지 주소로 교체합니다. 값이 `#`이면 이동하지 않고 준비 중이라는 토스트만 표시됩니다.

## 이미지 안내

현재 이미지는 게임용으로 제작된 가상 선글라스 이미지이며 실제 판매상품 이미지가 아닙니다. 실제 상품 이미지가 확정되면 `assets/`의 파일을 교체하고 `questions.js`의 경로와 대체 설명을 갱신하면 됩니다.
